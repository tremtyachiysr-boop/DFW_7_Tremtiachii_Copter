# DFW_7_Tremtiachii_Copter

**Маршрутна місія ArduCopter: PID і фільтр за логами SITL**

Фінальний проєкт курсу Drones Firmware. Студент: Тремтячий Сергій, група DFW-7.

Прошивка — ArduPilot (Copter 4.7.2), квадрокоптер Quad X у стандартному SITL ArduPilot (з візуалізацією в Gazebo Harmonic).
