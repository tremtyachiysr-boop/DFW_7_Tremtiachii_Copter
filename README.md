# DFW_7_Tremtiachii_Copter

**Маршрутна місія ArduCopter: PID і фільтр за логами SITL**

Фінальний проєкт курсу Drones Firmware. Тремтячий Сергій, група DFW-7.

Що зробив: налаштував квадрокоптер Quad X на прошивці ArduPilot Copter 4.7.2 у симуляторі SITL (з 3D у Gazebo Harmonic), пролетів місію з п'яти точок, перевірив повернення додому при втраті пульта, а по логах знайшов і виправив проблему з PID.
